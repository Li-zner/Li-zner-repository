# 机制库参考（agent_gateway 已验证的 15 项核心机制）

> ⚠️ 参考，不是规则。每项给「何时用 + 选型 + 关键注意」。

1. **JWT 认证**：密钥环境变量、无默认值；access 短时效 + refresh 轮换；登出黑名单。
2. **限流**：固定窗口（简单）/ 滑动窗口（Redis ZSET 精确）/ 令牌桶（Lua 原子）；登录严格、业务宽松。
3. **熔断**：按端点隔离（注册表模式），非全局单例；超时 + 失败率触发，半开恢复。
4. **分布式锁**：Redis `SET NX PX` + 唯一 token；释放用 Lua 校验持有者（防误删）；长任务看门狗续期。
5. **乐观锁**：`version` 字段 `WHERE version=?`，冲突重试 ≤3 次；扣款/余额必须锁 + 版本双保险。
6. **多级缓存**：L0 进程内存 → L1 Redis → L2 库；写后失效；防击穿互斥重建。
7. **语义缓存**（AI 类）：向量/相似度阈值命中，节省 LLM 调用。
8. **幂等**：幂等键存 Redis（带过期）+ 唯一索引双保险；结果缓存回放。
9. **事务边界**：锁、余额变更、流水同事务；写操作 service 层显式事务。
10. **连接池**：asyncpg 池 min/max；启动 fail-fast，不静默降级。
11. **SSE**：断连即取消上游任务（防资源泄漏）；`proxy_buffering off`。
12. **迁移**：Alembic；`ADD COLUMN IF NOT EXISTS` 补列；ini 保持 ASCII。
13. **Nginx 动态 upstream**：与运行实例同步（autoscaler 维护 + reconcile）；`connect_timeout 2s` + 全量重试。
14. **配置管理**：安全目录单一权威源；`_env.py` 统一读取；UNC/POSIX 双路径。
15. **结构化日志**：固定字段 + 脱敏；错误信息不暴露 DSN/内部路径。
