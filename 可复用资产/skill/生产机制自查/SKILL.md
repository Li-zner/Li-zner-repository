# 生产机制自查

目标：用数字定义「健康」，上线前逐项过一遍，缺什么补什么。源自 agent_gateway
生产实战（docs/生产级差距与核心机制手册.md），对任何后端/网关项目通用。

## 自查清单（24 项）

### 认证与安全（5）
- [ ] **JWT**：access 短时效（15min~2h）+ refresh 轮换（7~30 天）；校验 exp/iat/jti；密钥无默认值（fail loudly）；HS256 用常量时间比较
- [ ] **吊销**：jti 黑名单（Redis），踢人/泄露处置
- [ ] **密钥治理**：硬编码清零，统一 `_env.py`/环境变量；.gitignore/.dockerignore 排除；配置漂移校验（docker exec env vs 配置文件）
- [ ] **WAF/入口**：SQLi/XSS/路径穿越拦截（nginx map 403）；安全头；限流盾牌
- [ ] **注入过滤**：Agent 上下文与上传内容做指令注入过滤；敏感词 DFA

### 服务治理（4）
- [ ] **限流四维**：QPS/并发/日请求/日 token；Redis 原子计数（多实例一致）；角色分级；INCR 首次设过期
- [ ] **熔断**：三态状态机（CLOSED/OPEN/HALF_OPEN）；按端点隔离注册表；与超时/降级搭配
- [ ] **超时收口**：外部调用统一超时（connect/read/total 分级），无散落硬编码
- [ ] **断连取消**：流式接口客户端断开即取消生成任务（省 token 省资源）

### 数据与缓存（5）
- [ ] **连接池**：asyncpg min/max 按并发校准；`async with pool.acquire()` 用完必还；慢查询监控（pg_stat_statements）防池耗尽
- [ ] **索引**：B-tree（范围/等值）、GIN+trigram（模糊）、ivfflat（向量）；EXPLAIN ANALYZE 验证
- [ ] **事务**：资金操作「先取锁 → 开事务 → 读写 → 提交 → 释放锁」；改余额+记流水同事务
- [ ] **缓存三防**：穿透（存空值）/击穿（互斥重建）/雪崩（随机过期）
- [ ] **语义缓存**：阈值「宁 miss 不给错」；L0 进程内清库不清内存（重启才清）

### 资金与并发（4）
- [ ] **分布式锁**：SET NX EX + 唯一 token；释放必须 Lua（检查+删除原子）；TTL > 最长操作（超时需看门狗）
- [ ] **乐观锁**：version 字段 + WHERE version=$n；**必须检查 UPDATE 结果**；重试有上限
- [ ] **幂等**：订单状态机 + 幂等键 + 唯一约束 + 分布式锁；回调签名验签
- [ ] **WAL 流水**：只追加不可篡改；对账兜底（status=success 但无流水的孤儿订单修复）

### 工程化（6）
- [ ] **CI/CD**：语法检查（AST 不写文件）→ 构建（层缓存+commitSHA）→ 滚动发布（逐实例+健康门禁）→ 冒烟 → 失败回滚（记录 PREV_IMAGE）
- [ ] **数据库迁移**：Alembic 版本化；迁移幂等（IF NOT EXISTS）；临时库验证后再 stamp
- [ ] **SLO 告警**：错误率<1%、p95<5s、首 token p95<3s、成本日<50 元、缓存命中>30%；告警带 `for` 防抖动
- [ ] **可观测**：Prometheus 指标 + Tempo 链路（trace_id）+ Loki 日志（结构化+脱敏）
- [ ] **备份演练**：定期恢复演练（恢复临时库校验行数）；RPO=备份频率，RTO<30min
- [ ] **弹性伸缩**：按 QPS/CPU 自动扩缩；nginx upstream 与运行实例同步（Docker DNS 不解析已停服务！）

## 差距处置顺序

1. 按严重度排：资金/安全 > 稳定性 > 成本 > 体验
2. 每个差距记：现状 → 生产级要求 → 补齐方案 → 成本估算
3. 补齐后必须验证（压测/演练/测试），不留「脚本写了没跑过」

## 面试话术（30 秒）

> 「我的项目在生产化时按 SLO 定义健康：错误率<1%、p95<5s。补过的关键差距有——
> 支付并发安全（分布式锁+乐观锁双保险，修过三个真 bug）、缓存防击穿（互斥重建+随机过期）、
> 断连取消、慢查询监控。剩下的差距（集群、真实验签、KMS）我知道是什么，也有补齐计划。」
