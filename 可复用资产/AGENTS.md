# AGENTS.md — 可复用资产库入口（agent 必读）

> 本目录是个人 AI 开发的**可复用资产库**，不是某个项目的代码。本文件只做路由与红线速记；
> 进入哪个子目录工作，就遵守该子目录自己的 `AGENTS.md` / `README.md`（避免两处维护同一规则）。

## 目录路由

| 目录 | 是什么 | 何时进入、先读什么 |
|---|---|---|
| `vbcoding全流程/` | 日常开发流程：需求 → 编码 → 修 Bug → 审阅（三层按需读取） | 日常开发任务；**先读其 `AGENTS.md`**（任务路由表） |
| `harness/` | 新项目启动套件：规则原文 / 项目骨架模板 / 执行流程 | 从零启动新项目；读其 `AGENTS.md` 按序执行 |
| `MCP sever/` | 可复用 MCP Server：JWT / 分布式锁与限流 / 语义缓存 / RAG 检索 / 归因纠错 | 编码任务需要对应能力；读对应子目录 `README.md` |
| `可复用代码/` | 机制参考实现：分布式锁 / 限流器 / 熔断器 / LRU+TTL 缓存 / singleflight 幂等 | 需要机制的健壮参考；按机制名选文件，先读库内 `README.md` |
| `前端资产/` | 前端开发资产：开源项目三层选型清单 / Anthropic 官方前端技能 4 件 / 前端 MCP 接入文档 | 写、改、测前端或前端选型；先读其 `README.md` |
| `AI应用资产/` | AI 应用工程资产：agent 全链路 / RAG 构建链路 / 开源选型清单 / 官方技能（claude-api、mcp-builder） | 做 agent/RAG 项目、LLM 选型与开发；先读其 `README.md` |
| `skill/` | 技能库：Agent 开发全流程 / MCP 开发五步法 / 密钥治理 / 避坑清单等 | 需要对应技能；读对应 `SKILL.md` |

| `图谱/` | 知识图谱 MOC：按主题聚合全库双链（生产机制 / MCP / Agent / RAG / 安全 / 流程 / 前端） | 按主题浏览全库、查资产关联；先读 `MOC-总览` |

## 红线速记（细则在各子目录规则里）

- 遇 `[待定]` / 矛盾 / 凭据缺失 → 停下问人，禁止猜测
- 每步自测再进下一步；无自验证据不宣称完成
- 全库禁 emoji；LF 换行；函数 ≤80 行 / 文件 ≤600 行
- 密钥禁硬编码，统一 `.env`；破坏性操作（含删除 >1GB 文件）必须经人确认

## 约定

- 新增资产目录 → 在上表登记一行，并给该目录配自己的入口文件（`AGENTS.md` 或 `README.md`）
- 操作性规则只在一处定义：谁执行谁持有，其他文件只留指针
