- 旅行规划与路线推荐

规则说明：

1. 只有当用户问题明确或高度可能属于技术/工程类时，才应注入本规则到系统提示中。
2. 本规则旨在增强技术问题的准确性与结构化，不应影响日常业务场景。
3. 如果加载本规则，必须严格遵守其要求并保持回答简洁、专业。
4. 不要在回答中提及“我读取了规则”或“根据规则”。
