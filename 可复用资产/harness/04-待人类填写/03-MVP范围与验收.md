# MVP 范围与验收（人类填写）

> 划定阶段与验收标准。AI 每完成一个阶段必须对照验收，不达标不进下一阶段。

## 阶段划分建议（可按需增删）

| 阶段 | 范围 | 验收标准（人类填或默认） |
|---|---|---|
| 0 骨架 | 目录 + compose + /health + 密钥体系 | `/health` 200；`get()` 能读密钥 |
| 1 核心闭环 | 认证 + 核心实体 CRUD + 迁移 | 注册→登录→建实体→查询 全 200 |
| 2 加固 | refresh 轮换 + 限流 + 熔断 + 缓存 | 暴力登录 429；下游故障降级 |
| 3 可观测+多实例 | 指标/日志/告警 + Nginx 多实例 | 压测可见指标；单实例故障摘除 |
| 4 商业化 | 钱包/订单/幂等/对账（如适用） | 并发无超扣；对账一致 |
| 5 工程化 | CI/CD + 备份演练 + 安全加固 | 一键发布；演练恢复 |
