# 外部依赖与凭据（人类填写）

> 只填「键名 + 用途」，**值写进安全目录**（`/etc/<project>/.env`），不要写在本文件。

## 1. 必填密钥（AI 启动依赖）

| 键名 | 用途 | 是否必填 |
|---|---|---|
| `JWT_SECRET` | 签名密钥 | 必填 |
| `DB_USER` | 数据库用户 | 必填 |
| `DB_PASSWORD` | 数据库密码（特殊字符会被 URL 编码） | 必填 |
| `DATABASE_URL` | 完整连接串（容器内用服务名） | 建议 |
| `REDIS_URL` | Redis 连接 | 建议 |

## 3. 安全目录位置

- Windows 宿主机：`\\wsl.localhost\Ubuntu\etc\<project>\.env`
- Linux：`/etc/<project>/.env`
- 权限：`root:root 644`（不要 600，会挡 compose/宿主脚本读取）
