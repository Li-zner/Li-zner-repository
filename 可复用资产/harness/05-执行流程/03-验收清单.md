# 验收清单（AI 自检 + 人类复核）

> 分两类：**功能验收**（按 MVP 阶段）与**上线前强制清单**。

## A. 功能验收（每阶段）

见 `04-待人类填写/03-MVP范围与验收.md`。AI 逐条对照，标 ✅/❌/跳过(原因)。

## B. 上线前强制清单

### 功能闭环
- [ ] 核心链路（注册→登录→主业务→付费如有）全 200
- [ ] 非法入参/超长/空值/重复提交均有明确错误码

### 并发与数据
- [ ] 并发写（扣款/下单）无超扣、无丢失、无重复
- [ ] 幂等键生效（重复请求返回同一结果）
- [ ] 迁移可升级、可回滚

### 安全
- [ ] 全仓库 grep 无明文密钥（含历史）
- [ ] 登录/接口限流生效
- [ ] 日志无敏感明文
- [ ] 上传/LLM 注入防护生效（如适用）

### 可靠性
- [ ] 单实例故障 → Nginx 摘除不 502
- [ ] 下游故障 → 熔断降级不雪崩
- [ ] 缓存故障 → 回源可用
- [ ] 机器重启后脚本可恢复

### 可观测
- [ ] 指标/日志/追踪/告警（如启用）齐全
- [ ] SLO 定义并有对应告警

### 运维
- [ ] 一键启动脚本幂等可执行
- [ ] 备份脚本 + 恢复演练通过
- [ ] WAF/安全头就位（如对外）

## C. 交付质量
- [ ] 每段代码带注释
- [ ] 无 emoji、无调试残留、无无关文件
- [ ] 所有文件 LF
- [ ] 报告格式符合模板（完成/差异/风险/待确认/自测证据）
