# 踩坑清单（agent_gateway 真实故障，逐条对照）

> ⚠️ 参考。每一条都是线上/开发中真实踩过的坑。新项目遇到相似场景先查这里。

1. **配置漂移**：容器内密钥 ≠ 配置 ≠ git → 静默全链路故障（登录 500、支付全挂）。
   配置必须集中管理，改动走部署脚本 + 全链路探活。
2. **双 env 分叉**：安全目录与根 .env 各改各 → 改哪份都不生效。唯一权威源必须唯一。
3. **Docker DNS 不解析已停服务**：nginx upstream 残留已停实例 → reload 报
   `host not found in upstream`；请求挂连接超时（登录 499）。upstream 必须动态同步。
4. **compose 与手动容器命名冲突**：`container name /postgres is already in use`，
   `set -e` 卡死整脚本。基础设施步骤要容错。
5. **密码含特殊字符**：`# @ %` 必须 URL 编码（`quote_plus`）；alembic configparser 的
   `%` 插值会炸 → 不写 ini，直接传 URL。
6. **WSL 环境坑**：`localhost:5432` 被 wslrelay 拦截 → 用局域网 IP；WSL python 写
   Windows 盘 .pyc 会 PermissionError → 语法检查用 `ast.parse`。
7. **`CREATE TABLE IF NOT EXISTS` 不补列**：旧表加字段必须
   `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`。
8. **PSReadLine 2.0.0 + VS Code 终端集成**：命令被 `^U` 吃掉 → 升级 PSReadLine 2.4.5；
   终端坏了就换新终端。
9. **bash 脚本 CRLF**：Windows 编辑器写 CRLF → bash 报错。`.gitattributes` 强制 LF。
10. **env_file POSIX 路径在 Windows 失效**：要用 UNC `\\wsl.localhost\...`。
11. **Nginx depends_on 连动**：启动 nginx 必须 `up -d --no-deps`，否则连带拉起已停实例。
12. **推送输出被吞**：PowerShell 把 git stderr 当错误 → `*> file; Get-Content file` 确认。
13. **端口被 wslrelay 拦截**：部分 localhost 端口请求不到容器（实测 10091）→ 换端口。
14. **旧表缺列导致接口 500**：`init_db` 的 IF NOT EXISTS 不会给旧表补列，
   必须显式 ALTER 补齐后再上线。
