# 模板区说明

> 这里是可以**直接复制**的骨架与模板文件。新项目时：
> 1. 把 `项目骨架/` 整个复制到新项目根目录
> 2. 按 `04-待人类填写/项目协议` 修改端口、服务名、环境变量前缀
> 3. 参考 `03-参考-项目经验/` 填充业务代码
>
> 模板是**已验证的模式**，不要随意改变结构（端口/服务名可以改，分层不要改）。

## 文件清单

| 文件 | 用途 |
|---|---|
| `项目骨架/_env.py` | 零依赖密钥读取器（已含 UNC/安全目录支持，直接用） |
| `项目骨架/docker-compose.yml` | 编排骨架：app + postgres + redis + nginx（env_file 安全目录模式） |
| `项目骨架/Dockerfile` | Python 服务镜像（注意层缓存） |
| `项目骨架/start_all.sh` | 一键启动：单实例 + Nginx + 自动伸缩（幂等、容错） |
| `项目骨架/.gitignore` | 密钥/备份/产物排除 |
| `项目骨架/.gitattributes` | LF 强制 |
| `项目骨架/app/main.py` | FastAPI 入口骨架（lifespan + /health + 路由注册） |
| `项目骨架/app/core/config.py` | 环境变量配置骨架（无默认密钥） |
