# AI 应用资产

> **用途**：AI 应用工程师的全链路资产入口——agent 落地方法论、RAG 构建链路、开源选型清单、官方技能原件。
> **何时用**：启动 agent/RAG 项目、给 AI 应用选型、写 LLM 相关代码时进入本目录；先读本文件再按路由取用。

| 位置 | 是什么 | 何时用 |

## 与本库既有资产的分工（不重复）

- **流程纪律**：`../skill/AI Agent 开发全流程`（怎么管阶段与质量）——本目录管"每环节的技术怎么做"；
- **已验证代码**：`../MCP sever/`（RAG 双通道检索/语义缓存/JWT）、`../可复用代码/`（熔断/限流/幂等/预算守卫）；
- **工程流程**：`../vbcoding全流程/`（需求库/收敛循环/审阅）——AI 应用一样走这套，验收标准换成评测分；
- 本目录：开源选型 + 官方参考细节 + AI 特有链路（护栏/评测/可观测）。

## AI 应用工程师的成长主线（用本库怎么练）

1. **先立安全**：通读 `安全审计.md`，学会建威胁模型——这是首要考虑项，不是附加项；
2. **看链路**：通读 `agent全链路.md` + `RAG构建.md`，知道每环"为什么"；
3. **读参照**：agent_gateway 就是本链路的落地实体（限流/熔断/幂等/CDC/流式全有）——对照读代码；
4. **动手**：新项目走 `../harness/` 启动 + vbcoding 七阶段；RAG 知识库直接复用 `MCP sever/知识库双通道检索`；
5. **补课**：`skills/claude-api/shared/agent-design.md`（agent 设计）与 `cost-optimization.md`（省钱）必读；
6. **护城河**：评测集建设（第七节）——这是 AI 应用工程师区别于"调 API 的人"的分水岭；
   安全对抗用例集是护城河的护城河。
