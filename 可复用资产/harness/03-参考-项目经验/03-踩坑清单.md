# 踩坑清单（agent_gateway 真实故障，逐条对照）

> 注意：参考。每一条都是线上/开发中真实踩过的坑。新项目遇到相似场景先查这里。

1. **配置漂移**：容器内密钥 ≠ 配置 ≠ git → 静默全链路故障（登录 500、支付全挂）。
   配置必须集中管理，改动走部署脚本 + 全链路探活。
2. **双 env 分叉**：安全目录与根 .env 各改各 → 改哪份都不生效。唯一权威源必须唯一。
3. **Docker DNS 不解析已停服务**：nginx upstream 残留已停实例 → reload 报
   `host not found in upstream`；请求挂连接超时（登录 499）。upstream 必须动态同步。
4. **compose 与手动容器命名冲突**：`container name /postgres is already in use`，
   `set -e` 卡死整脚本。基础设施步骤要容错。
5. **密码含特殊字符**：`# @ %` 必须 URL 编码（`quote_plus`）；alembic configparser 的
   `%` 插值会炸 → 不写 ini，直接传 URL。
6. **WSL 环境坑**：`localhost:5432` 被 wslrelay 拦截 → 用局域网 IP；WSL python 写
   Windows 盘 .pyc 会 PermissionError → 语法检查用 `ast.parse`。
7. **`CREATE TABLE IF NOT EXISTS` 不补列**：旧表加字段必须
   `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`。
8. **PSReadLine 2.0.0 + VS Code 终端集成**：命令被 `^U` 吃掉 → 升级 PSReadLine 2.4.5；
   终端坏了就换新终端。
9. **bash 脚本 CRLF**：Windows 编辑器写 CRLF → bash 报错。`.gitattributes` 强制 LF。
10. **env_file POSIX 路径在 Windows 失效**：要用 UNC `\\wsl.localhost\...`。
11. **Nginx depends_on 连动**：启动 nginx 必须 `up -d --no-deps`，否则连带拉起已停实例。
12. **推送输出被吞**：PowerShell 把 git stderr 当错误 → `*> file; Get-Content file` 确认。
13. **端口被 wslrelay 拦截**：部分 localhost 端口请求不到容器（实测 10091）→ 换端口。
14. **旧表缺列导致接口 500**：`init_db` 的 IF NOT EXISTS 不会给旧表补列，
   必须显式 ALTER 补齐后再上线。
15. **显式插 id 未同步序列 → 首个自增 INSERT 撞主键**：迁移里
   `INSERT INTO t (id,...) VALUES (1,...)` 播种种子行后必须
   `SELECT setval('t_id_seq', max(id))`。否则下次 nextval 返回 1 撞既有主键，
   `tenants_pkey` 冲突，phone_register/phone_login 建租户首败、重试自愈（隐性间歇故障）。
   排查法：`SELECT max(id) FROM t` vs `SELECT last_value FROM t_id_seq` 对比。
16. **函数内局部导入的名字，模块级函数引用必然 NameError**：`from x import Y` 写在函数体内时
   Y 只绑定局部；同模块另一模块级函数引用 Y 直接 NameError，且被自身 `except Exception` 吞掉
   就变成功能静默失效（实例：某任务路径语义缓存从未写入成功，仅一句 warning 可查）。
   模块级函数用到的名字必须模块级导入。
17. **AST 规范门禁读不到注释**：`except: pass  # 说明` 仍被判静默违规（AST 无注释信息），
   要换成真处理语句（logger / 赋默认值 / continue）。
18. **passlib 1.7.4 × bcrypt ≥4.1 不兼容**：bcrypt 4.1 移除 `__about__`（版本探测告警）、
   72 字节超长密码从"静默截断"改"抛 ValueError"——存量截断兼容路径全崩，症状像"环境漂移"。
   锁 `bcrypt==3.2.2`（与 passlib 同代）或整体升 `bcrypt_sha256` 方案并全量升 bcrypt。
   排查法：单跑密码测试看栈是否落在 `passlib/handlers/bcrypt.py`。
19. **LLM 应用 markdown 渲染 XSS**：`marked.parse()` 默认放行原始 HTML，直插 `innerHTML` 时
   经 web_search/文件内容/提示词注入的 `<img onerror>` 可执行。渲染统一
   `DOMPurify.sanitize(marked.parse(text))`，且 CDN 引用必须锁版本（vendor 自托管更稳，
   jsdelivr 未锁版本=永远拉 latest）。
20. **Alembic revision id 撞车 → Cycle detected**：新迁移 ID 手拍（如 d4e5f6a7b8c9）可能
   与既有迁移重名，整链报环且难以定位。建新迁移前先全仓 grep 该 ID；用可排序的唯一前缀。
21. **老库"正常"掩盖迁移缺列**：迁移链从未创建某列而代码在写（如 users.email），老库因
   历史手工 ALTER 侥幸存活，全新环境 `alembic upgrade head` 后启动即崩。验收必须包含
   "全新空库跑完整迁移链 + 应用启动冒烟"，只测老库等于没测迁移。
