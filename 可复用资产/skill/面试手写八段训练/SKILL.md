# 面试手写八段训练

目标：**脱稿默写 + 讲清为什么**。每天 1-2 段：先手写 → 再对比 → 说清「这段在项目里对应哪里」
→ 次日重写前一天的。8 段一轮约 5-7 天，循环直到不卡壳。

## 八段清单（含要点与追问）

### 第 1 段：Redis 固定窗口限流（项目：rate_limit.py）
- 要点：① INCR 后首次设过期（防 key 无限堆积）② 并发计数超限要 DECR 归还 ③ 过期时间 = 兜底释放
- 追问：固定窗口缺陷？（边界双倍流量）→ 滑动窗口/令牌桶怎么改？

### 第 2 段：JWT 签发与校验（项目：auth.py）
- 要点：① `exp` 必带 ② `jti` 用于吊销 ③ 解码必须捕获 JWTError
- 追问：为什么无状态？（验签即验真，多实例适配）→ 泄露怎么办？（短 access + refresh 轮换 + jti 黑名单）

### 第 3 段：熔断器三态状态机（项目：circuit_breaker.py）
- 要点：① 三态流转（OPEN 超时 → HALF_OPEN；试探成功 → CLOSED）② CLOSED 时累计失败 ③ 按端点隔离
- 追问：熔断和超时关系？（先超时，超时也算失败）→ 熔断后降级？（返回兜底而非报错）

### 第 4 段：LRU 缓存（项目：semantic_cache.py 的 L0）
- 要点：① `move_to_end` = 标记最近使用 ② `popitem(last=False)` = 淘汰最旧 ③ 容量检查在 set 时做
- 追问：为什么 O(1)？（OrderedDict 双向链表+哈希）→ 不用 OrderedDict 怎么实现？（dict + 手写双向链表）

### 第 5 段：分布式锁 + Lua 原子释放（项目：payment/service.py）
- 要点：① `nx=True`（互斥）+ `ex=ttl`（防死锁）② 唯一 token（身份）③ 释放必须 Lua（不能先 get 再 delete）
- 追问：锁过期操作没做完？（看门狗续期）→ 主从切换丢锁？（Redlock，多数场景用不上）

### 第 6 段：乐观锁 UPDATE + 冲突重试（项目：payment/service.py）
- 要点：① `WHERE version=$3` 影响 0 行 = 冲突 ② **必须检查 UPDATE 结果**（不检查 = 余额没变流水照记）③ 重试有上限
- 追问：乐观 vs 悲观锁？（读多写少乐观，高冲突悲观/队列）

### 第 7 段：asyncio.gather 并行 + 异常隔离（项目：orchestrator.py）
- 要点：① `return_exceptions=True` 隔离异常 ② `isinstance(result, Exception)` 判断单个失败 ③ 信号量设上限
- 追问：协程里能放 time.sleep 吗？（不能，阻塞整个事件循环）→ 什么是 IO 密集？

### 第 8 段：FastAPI 依赖注入 + 认证（项目：auth.py）
- 要点：① `Depends` 注入 ② 依赖里抛 HTTPException = 自动 401 ③ 业务函数零污染
- 追问：依赖注入本质？（装饰器 + 函数参数解析）→ 怎么给接口加限流？（同样用 Depends）

## 训练安排（5-7 天一轮）

| 天 | 练习 | 验收 |
|---|---|---|
| D1 | 第 1 段限流 + 第 4 段 LRU | 10 分钟内默写，讲清 O(1) 和 INCR 过期 |
| D2 | 第 2 段 JWT + 第 3 段熔断 | 8 分钟内默写，讲清三态流转 |
| D3 | 第 5 段分布式锁 + 第 6 段乐观锁 | 10 分钟内默写，讲清为什么 Lua、为什么查结果 |
| D4 | 第 7 段 asyncio + 第 8 段依赖注入 | 10 分钟内默写，讲清 return_exceptions |
| D5 | 随机抽 3 段重写（模拟面试） | 不卡壳 |
| D6-7 | 全部 8 段盲写一遍 | 每段 ≤ 8 分钟 |

## 验收标准

面试现场随机抽任意一段：能写出来 + 讲出「项目里对应哪里 + 为什么这样设计」。
对照练习可用本库资产直接演示：`../../MCP sever/`（分布式锁与限流、语义缓存、JWT）
与 `../../可复用代码/` 的机制实现。

## 训练纪律

- 手写用纸笔或空白文件，先不翻答案
- 写完逐行对照：差在哪、为什么差（不是背答案，是理解设计）
- 每次训练后把卡壳点记入错题本，次日先重练卡壳段
