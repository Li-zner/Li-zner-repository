# 可复用开源前端项目清单（2026-09-05 星数经 GitHub API 实测）

> **用途**：回答"前端代码可复用吗"并给出按层次的取用清单。所有条目按本库规则评估过：
> 维护活跃、社区大、文档全；取用后仍须遵守本库编码规范（禁 emoji、LF、注释、命名）。
> **何时用**：启动新前端、给 agent_gateway/frontend 换装或扩功能、agent 写 UI 选型时。

## 结论：前端是可复用度最高的一层

前端复用分三层，越往上（整应用）省力越多、定制越少；越往下（原语）定制越自由：

1. **整应用复用**：AI 对话/工作台类产品直接拿成熟开源应用改造（open-webui、ai-chatbot）；
2. **组件/模板复用**：用 shadcn/ui 这类"代码复制进你项目"的组件体系 + 现成模板（tabler 等）；
3. **原语复用**：样式引擎（Tailwind）、无头组件（Radix/TanStack）、表单（react-hook-form）自由组装。

不建议复用的：别人项目的业务页面/路由/鉴权细节（与业务强耦合，改造成本通常高于重写）。

## 与本库其他资产的关系

- agent 写 UI 时：观感交给 `skills/frontend-design`，搭建交给 `skills/web-artifacts-builder`，
  组件来源挂 `mcp/前端MCP清单.md` 里的 shadcn MCP，验证挂 Playwright MCP + `skills/webapp-testing`；
- agent_gateway/frontend 改造时：层次二换组件体系风险大，建议按页面渐进替换；
  全新页面直接走 shadcn/ui 体系。
